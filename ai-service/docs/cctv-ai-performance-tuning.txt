1. DETECTION RESOLUTION
============================================================

Code:

small = cv2.resize(
    frame,
    (320, 180)
)

Purpose:

Resize the original CCTV frame before running AI detection.

Why:

AI models run much faster on smaller images.

Example:

Original CCTV:
2560 x 1440

Detection Resolution:
320 x 180

Benefits:
- Faster startup
- Lower CPU usage
- Faster face/head/person detection

Tradeoffs:
- Small faces may be missed
- Small heads may be missed
- Lower detection accuracy

Examples:

(160, 90)
Very Fast
Lowest Accuracy

(320, 180)
Recommended Balance

(640, 360)
Better Accuracy
Higher CPU

(1280, 720)
Very Accurate
Heavy CPU

============================================================
2. FRAME SKIP
============================================================

Code:

if frame_skip % 10 == 0:

Purpose:

Controls how often AI detection runs.

Examples:

%1

Detect every frame

Frame 1 -> Detect
Frame 2 -> Detect
Frame 3 -> Detect

Advantages:
- Highest accuracy
- Best tracking

Disadvantages:
- Highest CPU usage

------------------------------------------------------------

%3

Detect every 3 frames

Frame 1
Frame 2
Frame 3 -> Detect

Advantages:
- Good balance

Disadvantages:
- Moderate CPU

------------------------------------------------------------

%6

Detect every 6 frames

Advantages:
- Lower CPU

Disadvantages:
- Slight tracking delay

------------------------------------------------------------

%10

Current ICT Library Office Setting

Frame 1-9
No Detection

Frame 10
Detect

Advantages:
- Lower CPU
- Faster startup
- Better system stability

Disadvantages:
- Boxes update slower
- Fast-moving people may temporarily outrun boxes
