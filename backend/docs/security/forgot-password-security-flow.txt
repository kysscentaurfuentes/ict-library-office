# backend/docs/security/forgot-password-security-flow.txt

ICT LIBRARY OFFICE
Forgot Password Security Flow


REQUEST FORGOT PASSWORD OTP
 ├── Check IP request count
 │
 ├── CAPTCHA required
 │    ├── PASSWORD_RESET_BLOCKED log
 │    └── CAPTCHA_FAILED log
 │
 ├── IP temporarily locked
 │    └── Too many requests
 │
 ├── Generate OTP
 │    ├── Save hashed OTP
 │    ├── PASSWORD_RESET_REQUESTED log
 │    └── Send email OTP


VERIFY FORGOT PASSWORD OTP
 ├── Check forgot lock
 │
 ├── Check OTP expiration
 │
 ├── Invalid OTP
 │    ├── Increment failed attempts
 │    ├── Lock forgot password
 │    └── FAILED_FORGOT_OTP log
 │
 └── Valid OTP
      ├── Reset failed attempts
      └── Allow password reset


RESET FORGOT PASSWORD
 ├── Verify reset session
 │
 ├── Prevent same password
 │
 ├── Hash new password
 │
 ├── Update database password
 │
 ├── Delete reset session
 │
 └── PASSWORD_RESET_COMPLETED log
